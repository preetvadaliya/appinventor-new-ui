## Summary
Classes, templates and stylesheets that nothing references are deleted, together with the
stale entries in `YaClient.gwt.xml`. The compiled app is unchanged: users see no change in
classic or neo, light or dark.

## Why
Every later ticket moves or rewrites files; dead files would be moved for nothing and make the
file map lie. Each item below was checked with `git grep` on master (ba85eb0d0):
- `style/neo/NewYoungAndroidProjectWizardNeo.java` (58 lines) and `.ui.xml` (40 lines): the
  only mentions are inside the class itself.
- `UiStyleFactory.createNewYoungAndroidProjectWizard()` (`UiStyleFactory.java:52-54`): no
  caller, and `UiFactoryNeo` does not override it.
- `boxes/SourceStructureBoxClassic.java` (32 lines): implements `ISourceStructureBox`, never
  instantiated.
- `editor/youngandroid/YaProjectEditorClassic.ui.xml` and `YaProjectEditorCombined.ui.xml`:
  bound only by `ClassicUi` / `CombinedUi` (`YaProjectEditor.java:89-93`), which are never
  passed to `GWT.create`.
- `actions/ExportZipAction.java` and `actions/WindowOpenAction.java`: no reference in any
  `.java` or `.ui.xml` file. (`client/jzip/` stays: `local/LocalProjectService.java` uses it.)
- `client/variableColors.css` (1,116 lines): an older copy of `style/classic/variableColors.css`.
  `Ode.Resources` (`Ode.java:2757-2767`) only loads the `style/classic/` copy.
- `client/resources/{base,light,dark}.css` (10, 13, 13 lines of `@def`s): no `@Source`, no
  build rule and no other file names them.
- `TopToolbar.java:66` `WIDGET_NAME_DARK_THEME_ENABLED`: declared, never read.
- `Ode.java:43` imports `client.local.LocalTokenAuthService` and never uses it.
- `YaClient.gwt.xml:52,53,80,89` list source paths that do not exist: `client/jsonp`,
  `client/output`, `shared/jsonp`, `shared/rpc/launch`.

## Out of scope
- The `TokenAuthService` replace-with (`YaClient.gwt.xml:183-186`). It names
  `com.google.appinventor.shared.rpc.user.TokenAuthService`, which does not exist; the real
  interface is `shared.rpc.tokenauth.TokenAuthService` (`Ode.java:79,287`). So with
  `ant -Dlocal.services=true` (`appengine/build.xml:30,676`) the client still talks to the
  server instead of `LocalTokenAuthService`. It is a real bug, but fixing it changes how
  local-services builds behave, so file it as its own upstream issue.
- `style/classic/variableColors.css` and the `style/` token files (P2-05, P2-06)
- The rest of `UiStyleFactory` (P1-04)
- Redundant but valid `<source>` lines (subpackages of `client` are already included)

## Steps

3. Remove imports that become unused; do not reformat anything else.
4. Build and run the tests.
