## Summary
The contents of the shared dialogs, the blocks editor, the console, the data visualizer
and the admin list are styled from `features/public/features/base.css`, which reads tokens
only. The unused gallery block is deleted rather than moved. Classic and neo look exactly
as before.

## Why
These rules sit in the always-loaded `war/static/css/Ya.css` and are restyled per layout
in the two rules files. In `Ya.css` (excluding the dialog frame, which is controls, P6-36):
- 2046-2204 no-projects dialog (`.ode-noDialog*`), 20 rules; 2205-2274 project properties
  dialog (`.ode-propertyDialog*`), 10 rules; 2417-2448 dialog contents
  (`.settings-labeled-textbox`, `.uploadDialogContent`, `.buttonRow`, `.contentRow`,
  `.contentImage`), 5 rules; 3757-3783 barcode dialog (`.download-button`), 3 rules;
  3794-3859 appearance dialog (`.ode-UserSettingsDialog`, `.image-radio*`, used by
  `wizards/UISettingsWizard.ui.xml`), 12 rules; 3910-4137 list editor (`.lie-*`), 32 rules
- 487-598 data visualizer (`.ode-Component*`, `.cdbviz-dark`, toggled at
  `DataVisualizerPanel.java:131,659`), 19 rules; 437-486 admin user list, 4 rules;
  3894-3909 console `#aiConsolePanel`, 3 rules; 3648-3685 blocks (`.svg`, typeblock
  `.fi-*`, `.goog-hsva-palette`), 6 rules
- 831-903 layout helpers (`.ode-VerticalLayout`, `.ode-HorizontalLayout`,
  `.ode-Layout-spacing*`), 13 rules; 2031 `.FocusTrap`; 319 `.ode-MessagesOutput`;
  2449-2505 extension links and `.ode-Android-*`, 8 rules; 3860-3893 `.popup`, 5 rules
- 2822-3647 gallery, profile and moderation, 142 rules (826 lines). No client Java or
  `.ui.xml` sets its gallery classes (`.gallery-card`, `.app-stats`, `.ode-ModerationTable`
  …). `neo.css` (about 1674-1922) and `variableColors.css` (about 979-1205)
  copy 49 rules each.

Blocks rules also live in the rules files: `variableColors.css:1206-1230`
(`.blocklySvg text`, `.warningNav`, `.blocklyMainBackground`, `.blocklyCount`) and
`neo.css:1924-1935`.

## Steps
1. Before moving, grep `appengine/src`, `appengine/war` and `blocklyeditor/src` for each
   gallery class. Delete the gallery rules from all three files when nothing sets them
   (skip if P0-01 already did). List any class you keep in the PR description.
2. For each remaining class, collect its rules from `Ya.css`, `variableColors.css` and
   `neo.css`. Shared declarations go to `base.css` with `var(--token)` colours; per-layout
   differences go to that layout's `views.css`. Delete the originals.
3. Rewrite `url(../images/toolbarBG.png)` at `Ya.css:463` and `:522` to
   `../../static/images/toolbarBG.png`: `base.css` is served from `ode/features/`.
4. Keep `.cdbviz-dark` working with live light/dark: it must read the same tokens the
   rest of the page reads, or stay toggled by `DataVisualizerPanel` as today.
5. Keep the order of the layout helpers (831-903) relative to the dialog rules that
   override them (`.ode-DialogBox .dialogContent .ode-Layout-spacing*`, 2370-2392): the
   override must still win once one side lives in `base.css` and the other in `controls.css`.
