## Summary
The chosen layout becomes a `LayoutId` (`CLASSIC`, `NEO`) saved as the user setting
`UiLayout`, read through `UserPreferences.layout()`. Existing users keep their layout: the old
`NewLayout` boolean is migrated on first read. Users see no change.

## Why
The layout is a boolean, so a third layout cannot be expressed and every branch reads
"neo or not":
- `Ode.getUserNewLayout()` (`Ode.java:1479-1492`) parses `?ui=` by substring (`classic`, then
  `neo`), then reads `NewLayout`; `setUserNewLayout()` (`Ode.java:1499-1503`) writes it.
- Readers: `Ode.java:970` (`useNeoStyle`, declared at `Ode.java:146`), `Ode.java:1056`
  (CSS pick), `Ode.java:1786-1788` (neo welcome tip, which switches back to classic),
  `UISettingsWizard.java:56` (radio buttons). Writers: `UISettingsWizard.java:92,102`.
- `UiStyleFactory.createOde(Ode, String)` takes the strings `"modern"` / `"classic"`
  (`UiStyleFactory.java:27-28`, called from `Ode.java:1073`).
- `?ui=` is also parsed for the theme in `getUserDarkThemeEnabled()` (`Ode.java:1438-1443`).
- `NewLayout` is registered with default `"true"` (`GeneralSettings.java:40`,
  `SettingsConstants.java:32`), so a missing value already reads as neo.

## In scope
- New `core/layout/LayoutId.java`: `enum LayoutId { CLASSIC, NEO }` with pure-Java helpers
  `settingValue()` (`"classic"`, `"neo"`), `fromSetting(String)`, `fromNewLayout(String)` and
  `fromUiParameter(String)`, each returning `null` for unknown input. No GWT imports.
- New `core/settings/UserPreferences.java`: `static LayoutId layout()`,
  `static void setLayout(LayoutId)`, and the one `?ui=` parser (layout and theme part).
- `shared/settings/SettingsConstants.java` (outside `client/`): add `USER_UI_LAYOUT = "UiLayout"`.
- `settings/user/GeneralSettings.java`: register `UiLayout` as `TYPE_INVISIBLE` with default
  `""`, so "never saved" can be told apart from a saved value.
- `Ode.java`: delete `getUserNewLayout()` / `setUserNewLayout()`; `useNeoStyle` becomes a
  `LayoutId`; the readers above switch to `UserPreferences.layout()`;
  `getUserDarkThemeEnabled()` takes its `?ui=` override from `UserPreferences`.
- `UiStyleFactory.java`: `createOde(Ode, LayoutId)`.
- `wizards/UISettingsWizard.java`: reads and writes `LayoutId`.
- New test `appengine/tests/com/google/appinventor/client/core/layout/LayoutIdTest.java`.

## Steps
1. Add `LayoutId` and its test first. `fromUiParameter` keeps today's matching so bookmarks
   behave the same: contains `classic` -> `CLASSIC`, else contains `neo` -> `NEO`, else `null`.
2. Add `UserPreferences.layout()`: `?ui=` override, else `UiLayout`, else migrate from
   `NewLayout` (`"false"` -> `CLASSIC`, anything else -> `NEO`), else `NEO`. When it migrates,
   it writes `UiLayout` in memory; the next normal settings save persists it.
3. `setLayout()` writes `UiLayout` and keeps `NewLayout` in step (`NEO` -> `"true"`), so a
   rollback to an older build still opens the layout the user chose.
4. Switch every reader and writer listed in Why; delete the boolean accessors.
5. Replace the `"modern"` / `"classic"` strings in `UiStyleFactory.createOde` with the enum.
