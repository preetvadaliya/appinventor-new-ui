## Summary
Classic's colours and images become CSS custom properties in a static
`layouts/classic/public/classic/tokens.css` (light on `:root`, dark on
`:root[data-theme="dark"]`), and classic's rules file leaves the GWT `ClientBundle` as a static
file that reads them with `var(--name)`. Classic looks exactly as before, in light and dark.

## Why
- Classic's tokens are GWT `@def` constants: `style/classic/light.css` (76 lines, 48 `@def`s)
  and `style/classic/dark.css` (62 lines, 47; only light has `closed-backpack`). They are
  compiled with `style/classic/variableColors.css` (1,230 lines) into two separate bundles,
  `Ode.Resources.styleclassicLight()` / `styleclassicDark()` (`Ode.java:2757-2767`), so light
  and dark cannot change without a reload.
- GWT's `CssResource` substitutes a `@def` wherever its bare name appears in a value. The rules
  file uses 42 of the 48 names, 333 times on 325 lines, always as bare identifiers: no
  `value()`, `@sprite`, `@if`, `@eval`, `literal()`, `@url`, `@media` or `@import`.
- Line 7 is `@external .*;`, so class names are already unobfuscated; no template or Java
  code changes for the move. `Ode.Resources.Style` declares no methods.
- 12 light and 10 dark tokens are `url('static/images/…')` (one is
  `url('../blocklyeditor/…')`). Injected as a `<style>`, they resolve against the page today;
  from a file served under `/ode/classic/` they would resolve against the file.

## Steps
1. Write `tokens.css`: every `@def name value;` becomes `--name: value;`, light values under
   `:root`, dark values under `:root[data-theme="dark"]`. Carry over every token, including the
   six the rules never use (`closed-backpack`, `clr-primary`, `gray-75`, `gray-550`,
   `gray-650`, `gray-900`).
2. Rewrite each relative `url('static/…')` as `url('../../static/…')` (served at
   `/ode/classic/`). Both files sit in the same folder, so the result is the same whichever
   stylesheet a browser resolves a `var()` URL against.
3. Convert the rules with a throw-away script (do not commit it): inside declaration values
   only, replace each defined token name with `var(--name)`. Not in property names:
   `background-image: background-image;` (line 10) must become
   `background-image: var(--background-image);`. Leave undefined words alone:
   `background-color: border-color;` (line 9) is invalid today and stays as it is.
4. Delete `@external .*;`. Check that no `@def` or bare token name is left.
5. Wire the files through `ClassicLayout.stylesheets()`; P1-04's loader adds the links after
   `Ya.css` and waits for them, so there is no flash of unstyled content.
