## Summary
Before any nova code is written, one decision record fixes what nova is: which screens it
draws first, how its controls starts, its colour and icon set, and how it is offered to users.
The output is `docs/decisions/0007-nova-scope.md` in this repository, agreed with MIT in
the umbrella issue. No code changes.

## Why
P0 to P7 only restructure classic and neo; nova was kept out on purpose. Its only trace
today is a placeholder: the `layout: nova` label in `plan/labels.yml` uses `#2D1799`,
borrowed from the Blocks editor's Dictionary drawer (`blocklyeditor/src/blockColors.js:24`,
`Blockly.DICTIONARY_CATEGORY_HUE`), not a chosen brand colour. `map.json` sketches nova's
files (`NovaLayout`, `NovaControls` (map.json says "starts as StandardControls"; decision 0013 replaced that), `NovaShell`, `NovaTopBar`,
`NovaProjectList`, `NovaProjectToolbar`, `NovaMenus`, `NovaIcons`,
`public/nova/{tokens,controls,views}.css`), but nobody has agreed to that list. MIT's feedback
so far: neo stays the default and nova is offered as a third look.

## In scope
Decide and record, each with the reason and the options rejected:
- **Scope of the first release**: which views nova overrides (shell, top bar, project
  list and toolbar are the candidates) and which shared features it takes as they are
- **Controls**: settled by decision 0013: a full `NovaControls` written from day one
  (templates plus behaviour Java reusing `controls/behaviour/`); nova never extends
  `controls/standard`, classic or neo. Decide only the order in which they are written
- **Colour**: primary, surface and accent tokens for light and dark, contrast-checked
  (WCAG AA for text), and whether `#2D1799` survives as the label colour
- **Icons**: which icon font or SVG set, and its licence; every `IconKey` must be mapped
- **Offering**: how users pick nova (`UiLayout` value `NOVA`, the appearance dialog), and
  whether it ships behind a flag first
- **First tickets**: the list of Nova-milestone tickets that follow from the decision

## Out of scope
- Writing nova code, tokens or CSS
- Changing classic or neo, or the default layout
