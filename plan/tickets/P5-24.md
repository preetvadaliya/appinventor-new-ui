## Summary
`controls/Dialog` and `controls/Wizard` become the contracts every dialog is built on, with
`StandardDialog` and `StandardWizard` wrapping today's classes. The ARIA, Escape and focus
code that is copied across three classes moves once into `controls/behaviour/DialogA11y` and
`controls/behaviour/FocusTrap`. Users see no change.

## Why
- Three dialog bases exist. `widgets/DialogBox.java` (42 lines) only marks GWT's 3x3 frame
  table as layout (`TableAccessibility.setEnclosingLayoutTable`, line 40).
  `wizards/Dialog.java` (324 lines, class at line 31) adds role, `aria-modal`, a global
  Escape handler (lines 48-61), focus-first on `show()` (line 157) and focus restore on
  `hide()` (line 184). `wizards/Wizard.java` (359 lines) repeats the Escape handler
  (lines 99-110) and sets `aria-label` (line 96).
- Both Escape handlers are global `Event.addNativePreviewHandler`s added in the
  constructor and never removed.
- Focus trapping is hand-made: invisible `FocusTrap` buttons with `@UiHandler`s that bounce
  focus, in 11 files (for example `explorer/dialogs/NoProjectDialogBox.ui.xml:16,130`,
  `wizards/NewFolderWizard.ui.xml`, `explorer/commands/DeleteFileCommand.java:114-117`,
  `editor/simple/components/MockComponent.java`). `Dialog.isFocusable()` (line 271) has to
  skip them.
- All 11 `Wizard` subclasses add exactly one page (`addPage(` once each), so Back and Next
  are never shown.

## Steps
1. `controls/Dialog` (extends `IsWidget`): `setCaption`, `setContent(IsWidget)`,
   `addButton(Button)`, `show()`, `center()`, `hide()`, `isShowing()`, `setModal`,
   `setRole(String)` (dialog or alertdialog), `setAriaLabel`, `addCloseHandler`,
   `setEscapeHandler(Command)`. Keep the setter names `wizards/Dialog` already has
   (`setRole`, `setAriaModal`, `setAriaLabelledby`, `setAriaDescribedby`, `setAriaLabel`) so
   existing `ui.xml` attributes keep working.
2. `controls/Wizard` extends `Dialog`: `addPage`, `setFinishCommand`, `setCancelCommand`,
   `setOkEnabled`, `onPageInit`/`onPageFinish` hooks. Keep multi-page support even though
   no caller uses it today.
3. `DialogA11y.attach(dialog)`: sets the ARIA attributes, registers the Escape preview
   handler on show and removes it on hide, stores the trigger element on show and restores
   focus on hide (same deferred logic and `isElementValid` check as `Dialog.java`).
4. `FocusTrap.attach(dialog)`: on show, handle Tab/Shift+Tab at the first and last
   focusable element; on hide, detach. Same focusable test as `Dialog.isFocusable()`.
5. `StandardDialog extends wizards.Dialog implements controls.Dialog`; `StandardWizard extends
   wizards.Wizard implements controls.Wizard`. Same DOM and class names (`ode-DialogBox`).
6. Point `wizards/Dialog`, `wizards/Wizard` and `widgets/DialogBox` at `DialogA11y`; delete
   their inline Escape handlers. Leave the `FocusTrap`-class skip in place until the last
   hand-made trap button is gone.

## Acceptance criteria
- [ ] `wizards/Dialog.java` and `wizards/Wizard.java` contain no
      `Event.addNativePreviewHandler` call; Escape still closes every dialog and wizard.
- [ ] Opening and closing a dialog 20 times leaves no extra native preview handlers.
- [ ] Focus returns to the menu item or button that opened the dialog.
- [ ] A `StandardDialog` with `FocusTrap` keeps Tab inside the dialog with no invisible
      buttons in its markup.
- [ ] `Controls.active().dialog()` and `Controls.active().wizard(…)` return the standard pieces.
- [ ] Snapshot diff shows no change in classic or neo, light or dark.

## Rules
- At most ~400 added lines and ~20 files.
- No visual change; dialog DOM and class names stay the same.
- Old dialogs keep working; they move to the controls in P5-28 and P5-29.
- Short conventional commit subjects, e.g. `refactor(controls): dialog contract and a11y`;
  no AI attribution.

## How to verify
- `ant -Dskip.ios=true noplay`, `ant tests`, `ant BlocklyTest`
- Snapshot screens (P0-02), classic/neo × light/dark.
- By hand, in both layouts: Projects > Start new project, Escape closes it and focus returns to
  the menu button; Projects > Import from repository (a `Wizard`), Escape cancels it;
  Settings > User Interface Settings, Tab cycles inside the dialog.
- With a screen reader or the accessibility tree: role `dialog`, `aria-modal="true"`.
