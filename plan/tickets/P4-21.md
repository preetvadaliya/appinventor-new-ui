## Summary
The two root templates become each layout's shell and page views, one template per region
(decision 0008): `ClassicShell` (top bar, page, status bar), `ClassicProjectsPage`
(toolbar + list), `ClassicEditorPage` (design toolbar, `ClassicDesignerArea`,
`ClassicBlocksArea`, console) and `ClassicAdminPage`, with the `Neo*` equivalents.
`core/presenters/ShellPresenter` takes the non-visual wiring out of `Ode.initializeUi` and
picks the page; `core/presenters/EditorPagePresenter` shows the Designer area or the Blocks
area, one at a time. The window never scrolls; panes do. `UiStyleFactory` and
`UiFactoryNeo` go away. Users see no change at the snapshot size.

## Why
- `UiStyleFactory.createOde` (`UiStyleFactory.java:22-34`) picks one of two templates with
  `style.equals("modern")`, both bound to `Ode` as owner, so `Ode` carries 17 template
  fields (`Ode.java:237-259`) for whichever template ran.
- `Ode.initializeUi` (`Ode.java:1017-1135`) mixes boot wiring (editor registry, managers,
  RPC popup, window title, history and closing handlers, drag-and-drop) with frame
  building (deck panel, CSS pick, template, tab indexes), and turns page scrolling on
  (`Window.enableScrolling(true)`, `:1033`).
- Designer and Blocks share one set of columns. `showComponentDesigner`/
  `hideComponentDesigner` (`Ode.java:492-521`) hide the palette, tree and properties boxes
  (`setVisible` at `:493-495`, `:508-510`); `BlocksEditor.loadBlocksEditor`/
  `unloadBlocksEditor` move the `structureAndAssets` column and `BlockSelectorBox` around
  (`BlocksEditor.java:643-646, 664-666`) and toggle visibility (`:633, 647-648, 662,
  667-668`). `getWorkColumns`/`getStructureAndAssets` exist only for that (6 calls in
  `BlocksEditor`, 2 in `HTML5DragDrop`).
- The two templates are about 90% the same; neo differs in style names, sizes (classic's
  `width="240px"`/`"222px"`), its projects flex column (`style/neo/Ode.ui.xml:22`) and an
  "Assets" caption above the asset list (`:34-37`).

## Steps
1. `ShellPresenter` gets the non-visual part of `initializeUi`: editor registry (`:1018`),
   `FolderManager`, `ProjectManager`, `EditorManager` (`:1020-1022`), RPC status popup
   (`:1024-1029`), window title (`:1032`), expired-service check (`:1035-1037`), history
   handler (`:1111-1116`), window-closing handler (`:1122-1127`), `HTML5DragDrop.init()`
   (`:1129`), user email (`:1130`, via `TopBarPresenter`) and the splash decision
   (`:1131-1133`). `View`: `showPage(Page)` (`PROJECTS`, `EDITOR`, `ADMIN`) and
   `showTutorial(boolean)`, as in the example.
2. `EditorPagePresenter` (`Mode { DESIGNER, BLOCKS }`, `showMode`, `showConsole`) replaces
   the `setVisible` calls and column moves above; `DesignToolbarPresenter`'s switch to
   Blocks/Designer calls it. Keep the hidden-components checkbox toggle (`:498, 513`) on
   the mode change until P5-43.
3. Templates per decision 0008: shell `col screen` with top bar, a `row grow` page area
   (pages + tutorial) and status bar; pages `col grow`; areas `row grow` with one column
   per box. Pages switch by `setVisible` from `showPage` (no `DeckPanel`); keep the
   context-menu blocking (`:1041-1051`) on the page area. A box is a singleton widget, so
   the two that both areas show (`ViewerBox`, `AssetListBox`) sit in `SimplePanel` slots
   and `showMode` moves them into the shown area.
4. Full height: `Window.enableScrolling(false)`, `reset.css` gains `overflow: hidden` on
   `html, body`; `grow` passes height down; only project rows, box bodies, the phone
   preview and trees are `overflow-auto`; Blockly scrolls itself.
5. Boot: `layout.shell()` → presenters → `RootPanel.get().add(view)`. Keep the pinch-zoom
   handler (`:1094-1105`) and the dyslexic class (`:1107-1109`) in `Ode`.
6. Delete `UiStyleFactory`, `UiFactoryNeo`, `Ode.uiFactory` (`:296`) and its uses (`:987,
   1006, 1018, 1020, 1054`).

## Acceptance criteria
- [ ] Each layout has the six views above, every box an `<g:HTMLPanel>` and no raw `<div>`/`<span>`;
      `Ode` has no `@UiField`s; `client/ShellBinders.java` is gone.
- [ ] `ShellPresenter`, `EditorPagePresenter` import no GWT widget and nothing in `layouts/`.
- [ ] No `setVisible` on a box and no column move remain in `Ode` or `BlocksEditor`;
      `getWorkColumns`/`getStructureAndAssets` are gone.
- [ ] The window never scrolls: at 1280×600 `document.scrollingElement.scrollHeight`
      equals `innerHeight`; project rows, box bodies, the phone preview and trees scroll
      inside. (The one intended change: on short windows panes scroll, not the page.)
- [ ] `UiStyleFactory`, `UiFactoryNeo` are gone; `grep -r uiFactory client/` is empty.
- [ ] Projects, Trash, Designer, Blocks and Admin open as before; tutorial and console
      open and close; right-click on the page area shows no browser menu.
- [ ] Snapshot diff shows no change in classic or neo, light or dark.

## Rules
- Boxes are placed, never copied or subclassed. A layout never imports another layout.
  Templates follow decision 0008; today's style names stay next to the flex classes.
- At most ~400 added lines and ~20 files: ship as `(1/3)` the two presenters and the `Ode`
  wiring with the old templates (steps 1-2), `(2/3)` classic views, `(3/3)` neo views and
  the factory deletion.
- Branch `ui/p4-21-shell-views`; PR title `[new-ui P4-21] Each layout owns its page frame`;
  commits like `refactor(views): page frame per layout`; no AI attribution.

## How to verify
- `ant -Dskip.ios=true noplay`, `ant tests`, `ant BlocklyTest`; snapshot screens: all 8.
- By hand in both layouts: start with `?locale=de`; open a project, switch to Blocks and
  back; drop a file on the designer; open a project with a TutorialURL and toggle it and
  the console; Trash and back; Admin as an admin; Back/Forward between projects; close
  with unsaved changes; shrink the window to 600 px high and scroll each pane.
